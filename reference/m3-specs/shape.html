Using shape morph

link
Copy linkLink copied

Access to the Material shape library and the shape morph functionality are available through a platform-specific API.

  • For Android, use the Shapes in Compose API
  • Web is not currently available

Shape morphing uses the expressive motion scheme The motion physics system has two schemes: standard for utilitarian movement, and expressive for more bouncy movement. More about motion schemes by default. This can be switched to the standard motion scheme as needed.
