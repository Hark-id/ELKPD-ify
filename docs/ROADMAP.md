# Roadmap

Shared goals for ELKPD-ify, agreed by both developers. Every item lands as
issues + PRs per the protocol in `AGENTS.md`. Order is priority, not schedule.

## Now

1. **Auto-fitting answer fields** — text adapts to the box so answers never
   need manual font-size fiddling (the Canva pain this project answers).
   → #1

## Next

2. **Generic PDF import** — replace the hand-rebuilt worksheet with a
   pipeline that extracts text runs, fonts, and vector fills from any PDF
   (PDF.js) and produces the editable sheet automatically.
   → #2

## Later

3. **Accounts, saved projects, per-user access** — Canva-style model:
   profiles own projects, share with chosen people; rooms become the
   live-collaboration layer inside a project. Design doc first.
   → #3
